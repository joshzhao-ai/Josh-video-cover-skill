# Codex Showcase Strategy

这条路线只服务 Codex / GPT Image 2。Seedream / Dreamina 稳定路线不要套用这里的规则。

## 核心目标

Codex showcase 路线不追求“稳定生成三张相似可用图”，而是追求：

> 美感好，表达清晰，有点击欲，并且三张候选是真正不同的封面方向。

生成前先回答四个问题：

1. **封面承诺**：这张封面承诺用户能得到什么？
2. **低门槛输入**：这件事为什么显得容易开始？
3. **高价值结果**：用户最终想要的具体结果是什么？
4. **画面证明**：封面用哪些视觉物件证明这个承诺成立？

## 标题原则

Codex 路线优先让主标题写：

> 低门槛输入 + 高价值结果

副标题写：

> 技术路径 / 方法补充

例如 AI 3D 打印视频：

- 主标题：`一张图 / 做出3D手办`
- 副标题：`AI建模 + 一键拆件`

这比 `3D打印 / 2分钟搞定` 更强，因为“3D手办”是用户想要的结果，“一张图”是低门槛输入。

## 画面原则

画面必须证明标题，不只是堆元素。

常用结构：

- **人物负责信任**：真人可以做账号识别和讲解者背书，但不能抢走结果物。
- **结果负责点击**：最终成果必须足够大，最好一眼就懂。
- **流程负责证明**：只保留最小证明链路，例如 `输入图 -> AI建模界面 -> 成品手办`。
- **背景负责氛围**：背景 UI、网格、代码、粒子都必须退后，不要变成信息噪音。

### 真人 × 品牌物互动

当视频围绕一个明确产品、模型、工具或品牌，用户选择真人，而且有官方 Logo / 产品图时，可以选择 `creator_product_interaction`：

> 巨大短判断标题 + 有态度的真实人物 + 一个被实体化的官方品牌物 + 一个能记住的互动动作。

品牌物不能只是角落贴纸。优先设计成抱住、递向镜头、磁吸、开启等动作，让人物真的和它发生关系。品牌外观必须来自官方 `content_reference`，风格参考只负责标题尺度、广角透视和互动节奏；绝不从其他创作者封面抠 Logo，也不把 Kimi 的蓝色语法套给所有品牌。

这类封面允许更强的情绪和 24-28mm 广角感，但人脸、体型、服装和手指必须稳定。完整规则见 [creator_product_interaction_playbook.md](creator_product_interaction_playbook.md)。

如果视频里有清晰真人出镜，进入生图前必须先让用户选择是否嵌入人像。即使最终推荐“结果物优先”或“无人证明链”，也要把“上传人像 / 取视频帧 / 不放人像”交给用户决定，不能由智能体自动跳过。

## 三张候选必须是路线级差异

不要再做同一个母版的三种姿势。Codex showcase 默认三路：

1. **结果爆款版**：结果物最大、标题最冲、适合信息流点击。
2. **流程证明版**：输入、工具、结果链路最清楚，适合教程内容。
3. **场景实物版**：真实使用场景或结果场景最强，适合证明“真的能做出来”。

如果视频不是工具实测，可以替换为：

- **人物背书版**：真人 + 方法卡 + 一个强承诺。
- **痛点反差版**：错误做法/痛点 vs 正确结果。
- **实物对比版**：前后对比、改造前后、结果对照。

若选择 `creator_product_interaction`，三张路线至少要改变互动机制：例如“双手持物 / 向镜头递近 / 动态吸附或开启”。不能只换人物姿势或背景颜色。

## 横版不是扩图

4:3 要继承同一 campaign 的不可变项：确认文案、人物身份和服装、官方品牌物、主色、字体材质、互动关系。它不必继承竖版的像素位置。

横版允许重新安排断行、机位、景别和前后景，甚至把“平面持物”改成“广角递近”，前提是仍讲同一件事。主标题应占视觉面积约 45%-60%，人脸不能退成远景，人物、品牌物和标题要通过遮挡与透视组成一张原生横版海报。

## 抽帧策略

如果只是理解视频，12-20 帧够用；如果是为了 Codex showcase，应该额外找“证明标题的帧”：

- 开头钩子段：多看，找低门槛输入或问题引入。
- 结果展示段：加密抽帧，找最终成果。
- 场景变化点：前后补帧，避开转场、字幕遮挡和糊帧。

最终不是把所有帧喂给模型，而是筛出 6-12 张候选证据帧，用来支持标题与画面规划。

## 负向规则

- 不要让三张都用同一个人物位置、同一个配色、同一个主体、同一个标题布局。
- 不要把功能词当主标题，除非功能词本身就是用户结果。
- 不要用大量小 UI、任务列表、能力地图假装有信息量。
- 不要为了点击编造数字、成绩、权威背书或结果。
- 不要让副标题和证据卡变成乱码装饰；宁可少写。

## 交付判断

一张 Codex showcase 封面合格，不是因为“元素都在”，而是因为缩小到信息流尺寸后仍然成立：

- 第一眼：主标题能读懂，有点击理由。
- 第二眼：结果物或证据物能证明标题。
- 第三眼：人物、流程或场景增强可信度。

如果只是在大图里细节丰富，但缩小后主题不清楚，应该判失败。
