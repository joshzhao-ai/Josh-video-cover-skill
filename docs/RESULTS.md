## 如何理解这些数字

- **展示范围：** 单个作者账号的四个精选案例，不能视作所有生成封面的平均成绩。
- **统计口径：** 使用后台原字段“播放”和“封面点击率”。没有把“详情页进入率”“完播率”等字段混入。
- **精度：** “万”为后台显示的近似单位，未反推精确播放次数；不把 99.1 万四舍五入写成 100 万。
- **结论范围：** 说明 Skill 已用于真实发布且有可核对的作品成绩。视频内容、选题、分发等因素也影响表现；当前数据不构成封面独立贡献的 A/B 实验证明。
- **图片对应：** Codex、Kimi、Claude Code vs Codex 的独立封面已与截图核对；Claude 的后台缩略图与数据可核对，首页原图位置暂留，等待作者补充。
