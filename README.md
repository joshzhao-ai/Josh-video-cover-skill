## 像和设计师一起做封面

视频剪完了，封面还要决定：**最值得讲的是什么？标题怎么写？用人像还是产品？横版怎么排？**

把视频交给 Skill，它会分析内容、提炼标题、匹配视觉方向、调用图像模型并检查成片。你保留对标题、人像和最终方向的决定权，无需自己编写生图提示词。

```text
你：给这个视频制作封面。 [附上本地视频]

AI：查看关键帧，提炼主题、亮点和可用于画面的内容证据。
    给出标题候选，同时询问使用上传人像、视频取帧，还是不放人像。

你：1B。 [附上人像照片，选择标题 B]

AI：生成并检查 3 张不同视觉方向的 3:4 封面，直接在对话中展示。

你：选第 3 张。

AI：延续选中方向，生成 2 张原生 4:3 横版候选，检查后供你选择。
```

**一次制作，获得标题方案、三条竖版创意路线，以及选中方向的横版延展。**

## 把封面经验，变成可以执行的设计方法

### 01 · 从内容里找到值得点击的理由

先查看视频关键帧，再提炼“讲什么”和“为什么值得看”。标题和画面围绕同一个亮点展开：教程展示结果，测评突出产品，知识内容呈现核心问题。

标题里的数字、效果和成绩必须有内容依据。画面也要有相应的产品、实物或结果作为支撑，让封面的吸引力来自视频本身。

### 02 · 根据题材组织画面

把构图、主体、背景、光影、字体与配色拆成可以组合的视觉配方。美食的食欲、产品的质感、知识内容的信息层级，各有合适的表达方式。

| 视频题材 | 视觉设计方向 |
| --- | --- |
| AI 工具、真人口播 | 人物态度、点题动作与工具或结果物互动 |
| 数码、产品测评 | 产品主视觉、金属与玻璃质感、影棚光影 |
| 拆机、维修、实物操作 | 手、工具与实物的关系，微距细节 |
| 美食纪录片 | 食物特写、热气与光泽、电影感布光 |
| 医学科普 | 医疗符号与主题器械，清晰的视觉解释 |
| 设计、排版教程 | 字体、色彩和版式本身成为示范 |
| 摄影、生活氛围 | 暖调胶片、自然光、颗粒与生活场景 |

题材配方提供起点；三张候选还要在构图、主视觉、配色和表达方式上拉开差异，给你真正有价值的选择。

### 03 · 让横竖版成为同一套作品

选中的竖版会成为横版续作的参考。保留标题、人物、主物、配色和字体材质，为 4:3 重新设计断行、景别与空间关系。

这套流程适合需要同时准备竖版与横版封面的创作者，也让后续调整有明确的依据：改的是同一个创意在不同尺寸下的表达。

### 04 · 按真实观看尺寸验收

一张封面既要经得起放大，也要在信息流里看得懂。工作流要求逐张检查原图与缩略图：竖版 **180 × 240**，横版 **320 × 240**。

第一眼读懂主题，第二眼看到结果或证据，再看到人物与氛围。错字、标题过小、人像漂移、肢体异常和候选同质化，都进入定向重做流程。

### 05 · 让不同模型发挥各自的能力

视频分析、标题、人像和创意方向可以复用，生成策略分别适配。

| 路线 | 生成策略 | 运行条件 |
| --- | --- | --- |
| Codex / GPT Image 2 | 明确画面关系，分别指定身份、内容与风格参考图的职责 | Codex 环境可用 `image_gen` |
| Dreamina / Seedream | 按题材使用短中文视觉配方，按需加入人物与准确品牌资产 | 已安装、登录并可调用的 Dreamina CLI |

Dreamina 路线会探测本机支持的模型版本，并如实记录。模型名称、版本与可用能力以实际运行环境为准。

## 从单次出图，到持续迭代

项目把封面制作拆成七个可检查的环节：

**视频抽帧 → 内容理解 → 人像与标题确认 → 题材匹配 → 多路线生成 → 逐张质检 → 双尺寸交付**

背后包括标题策略、题材配方、流程状态记录、模型适配器，以及固定变量的评测协议。发现问题后，可以定位到对应环节，保留失败原因并改进规则。

当前仓库提供可运行的 v2 工作流、人工筛选的双尺寸案例和回归评测材料。展示案例用于说明设计能力；批量可用率和点击率提升仍需独立验证。评测方法见 [EVALUATION.md](EVALUATION.md)。

## 开始使用

> 当前 v2 位于 `agent/showcase-v2` 分支，下面的命令会安装该版本。需要能读取本地视频、执行 Python/FFmpeg，并调用图像生成工具的 Agent 环境；模型调用使用你自己的账号与可用额度。

### Codex

首次安装（目标目录应不存在）：

```bash
git clone --branch agent/showcase-v2 --single-branch \
  https://github.com/joshzhao-ai/Josh-video-cover-skill.git \
  ~/.codex/skills/video-cover-generator

python3 -m pip install -r ~/.codex/skills/video-cover-generator/scripts/requirements.txt
```

安装 FFmpeg，macOS 可使用：

```bash
brew install ffmpeg
```

其他系统请安装对应的 FFmpeg，并确保终端能运行 `ffmpeg` 和 `ffprobe`。

重新打开 Codex 任务，附上本地视频并说：

```text
给这个视频制作封面
```

环境具备 `image_gen` 时，按 Skill 默认路线调用。使用 Dreamina 路线时，可以说：

```text
用即梦给这个视频制作封面
```

## 常见问题

**必须上传自己的照片吗？**

有真人的视频会让你选择上传照片、使用清晰视频帧，或不放人像。清晰人像更有利于身份一致性；取帧重绘仍可能产生偏差，需要检查成片。

**需要会设计或写提示词吗？**

按对话选择标题、人像和喜欢的方向即可。你也可以补充风格偏好、必须出现的产品或希望强调的内容。

**生成后可以直接发布吗？**

工作流以可发布封面为目标，并包含逐张检查与重做。生成模型仍可能出现错字、手部异常或人物偏差，最终发布前请确认文字、身份和素材使用权限。

**能做批量测试和模型对比吗？**

仓库提供评测材料。比较时固定原视频、标题、人像、比例与路线，每次只改变一个变量，具体见 [评测协议](EVALUATION.md)。
