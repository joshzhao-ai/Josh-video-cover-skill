## 保留的设计要点

1. **痛点比部署动作更适合作为大标题。** 初版“搬进云电脑”说明方法；用户希望突出“防封号”。最终用“防封号新思路”，对应视频展示的个人使用思路，没有包装成完整操作教程。
2. **主题锚点与中文钩子分级。** 顶部米白色 `Claude Code` 负责识别主题，橙色六字标题分两行占据上半部，缩略图仍能读完整。
3. **黑橙高对比与少量颗粒。** 近黑背景、橙色粗重字、米白云朵；暖橙光把笔记本、角色与云朵统一在同一空间。
4. **一个场景表达一件事。** 云朵从笔记本屏幕涌出，像素角色站在键盘上，表达工具进入云端工作环境。没有额外功能卡、UI 拼贴和解释列表。
5. **删掉没有必要的小字。** 用户明确要求去掉“美国云电脑实测”，并认可去除后的黑橙版。此案例复用时默认保留“主题锚点＋主标题”，不补角标来填空。
