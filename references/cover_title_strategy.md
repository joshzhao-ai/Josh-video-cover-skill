# Cover Title Strategy

封面标题不是视频标题，也不是纯钩子。它只做两件事：

> 让目标用户认出主题，并给他一个现在点开的理由。

## 两段式

一个封面标题 = **锚点 + 理由**。

- **锚点**：让用户知道这条视频讲什么。可以是专有名词，也可以是任务对象或具体动作，例如 `Agent Skills`、`Codex`、`Claude Code`、`Skill`、`写 Skill`、`做一个 Skill`、`AI 工作流`、`安装`、`调用`、`封装`、`复用`。
- **理由**：让用户觉得值得点。可以是内容范围、用户收益、痛点、好奇、反差或已验证结果。

不要把锚点理解成“每版都必须同一个词”。三版标题可以分别用 `Agent Skills`、`做一个 Skill`、`不会写 Skill？` 作为锚点；关键是每一版都要让人知道内容对象，而不是只剩泛 AI 情绪。

## 三版候选

默认给 3 个候选，区别在“理由”：

1. **稳妥清晰版：锚点 + 内容范围**
   - `Agent Skills / 从安装到实战`
   - 适合教程、解释、系统课。优点是清楚，缺点是教程感可能稍强。

2. **收益承诺版：锚点 + 用户收益**
   - `做一个 Skill / 让 AI 反复干活`
   - 通常优先推荐。它告诉用户看完能多会什么、少做什么或做出什么。
   - 对视觉创作、内容生产和效率工具，可优先测试“具体工具/输入 + 向往身份结果”，例如 `一个 Skill 搞定 / 百万博主口播感`。

3. **任务型探索版：锚点 + 痛点/好奇/反差**
   - `不会写 Skill？ / 这条讲清楚`
   - 可以更口语、更破圈，但不能空泛。必须保留具体任务对象或具体动作。

## 向往身份转换

当工具的直白功能准确但不够有点击欲时，不要停在“会什么”，继续问用户“想让自己看起来像谁、达到什么状态”。

按以下顺序生成：

1. 写出工具的真实动作，例如 `分析房间 + 给出布光布景方案`。
2. 找到动作对应的专业角色，例如 `打光师 / 场景设计师`。
3. 换成受众更向往、同时与内容相关的身份或观感，例如 `百万博主口播感`。
4. 套入“小投入换大结果”的句式：`一个 X 搞定 Y`、`一张 X 搭出 Y`。

可复用公式：

> **具体工具或输入 + 极简动作 + 向往身份的具体结果**

示例：

- `一个 Skill 搞定 / 百万博主口播感`
- `一张房间图 / 搭出专业口播间`

向往身份不能代替任务信息。`百万博主视觉感`略泛，能收窄时优先写成`百万博主口播感`、`专业测评画面`等与视频任务直接相关的结果。

## 证据铁律

涉及数字、成果、`最/第一`、排名、收入、涨粉、媒体曝光、权威背书、`靠 X 做到 Y` 的标题，只能在视频分析结果、字幕、原视频标题、用户补充或可见素材里确实有这个事实时使用。

没有证据时，换成普通说法：

- 可以写：`一条讲透`、`从安装到实战`、`小白也能上手`
- 不要编：`3个月涨粉10万`、`靠 Skill 上了央视`、`行业第一`

`百万博主口播感`属于观感类比，不是粉丝结果承诺；只有视频确实展示了画面、场景或质感升级时才可使用。可以写`百万博主口播感`、`大博主同款观感`，不要写`让你成为百万博主`、`轻松涨到百万粉`或`百万博主都在用`，除非有明确证据。

`证据依据` 和 `证据物` 分开看：

- **证据依据**：支撑强结果标题的事实来源，例如字幕、视频标题、用户确认、画面可见数据。
- **证据物**：封面里的视觉物件，例如笔记本、流程卡、`SKILL.md` 文件树、产品截图、数据图。证据物可以增强“这条视频有东西”，但不能替代事实依据。

## 反例

- `AI工具介绍`：太像摘要，没有获得感。
- `真实感受分享`：没有具体锚点，也没有理由。
- `别只会问 AI`：有情绪，但如果没有 `Skill`、`Codex`、`工作流` 等锚点，主题识别不足。
- `给它装个技能`：比喻感有，但任务信息量不足，不知道是 Skill、插件、提示词还是工作流。

## 输出格式

给用户选择时，每个候选写清：

- `标题大字`：1-2 行，缩略图第一眼读到。
- `类型`：稳妥清晰 / 收益承诺 / 任务型探索。
- `锚点`：这版靠什么让用户认出主题。
- `理由`：这版靠什么让用户想点开。
- `证据依据`：只有用到数字、成果、权威等强结果时才写；没有则写“无”。
- `证据物`：画面里可用来证明内容含金量的物件或场景。
